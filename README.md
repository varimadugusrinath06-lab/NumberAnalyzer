# NumberAnalyzer

A menu-driven C program that checks, lists, and counts special types of numbers.

## Supported Number Types

- Prime numbers
- Perfect numbers
- Strong numbers
- Armstrong numbers
- Palindrome numbers

For each type, the program can:

1. Check one number
2. Find matching numbers within a range
3. Count matching numbers within a range

## Requirements

- A C compiler such as GCC
- A terminal or command prompt

## Build and Run

Compile the program:

```bash
gcc number_analyzer.c -o number_analyzer
```

Run it:

```bash
./number_analyzer
```

## Example

```text
=== Number Analyzer =======
1. Prime Number
2. Perfect Number
3. Strong Number
4. Armstrong Number
5. Palindrome Number
6. Exit
```

Choose a number type, then select whether to check a single value, analyze a range, or count the results.
